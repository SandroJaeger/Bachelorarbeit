\begin{kurzdarstellung}
    Damit ein KI-Agent eine dreidimensionale Szene natürlichsprachlich verändern kann, muss ihm die Szene zunächst in einer verarbeitbaren Form vorliegen.
    Dafür stehen zwei grundlegende Wege zur Verfügung, eine strukturelle Beschreibung als exakte Daten und eine visuelle Beschreibung über ein gerendertes Bild.
    Für selbst gehostete Modelle geringer Größe fehlte bislang ein systematischer Vergleich dieser Formen.

    Die vorliegende Arbeit untersucht daher, welchen Einfluss die Repräsentationsform auf den Ausführungserfolg der Szenenmanipulation hat und ob sich eine Kombination beider Formen gezielt gestalten lässt.
    Dazu wurde ein prototypisches System entwickelt, das dieselbe Szene strukturell, visuell und hybrid bereitstellt und fünf daraus abgeleitete Varianten unter gleichen Bedingungen an dreizehn kontrolliert aufgebauten Szenarien vergleicht.
    Die Messung selbst fand am Desktop statt; die immersive Umgebung wird ausschließlich in einem Demonstrator gezeigt und nicht eigenständig evaluiert.

    Der Vergleich zeigt eine referenztypabhängige Kompetenz ohne Gesamtsieger, wobei beide Formen jeweils einen Bereich abdecken, den die andere nicht erreicht.
    Eine naive Kombination vereint diese Stärken nicht von selbst.
    Erst eine ausdrückliche Trennung der Zuständigkeiten führt die beiden Schichten auf diesem Szenarioset zusammen, während eine bloße Priorisierung das Gewicht nur verschiebt.
    Ob sich dieser Vorteil auf ungesehene Formulierungen überträgt, bleibt offen, da die Variante iterativ am vorliegenden Szenarioset entwickelt wurde.
    Ein Demonstrator überträgt diese Variante in eine immersive Umgebung und zeigt die Machbarkeit der gesamten Kette.
\end{kurzdarstellung}
